# Process documents

This folder holds the working logs of the [BMAD](https://github.com/bmad-code-org/BMAD-METHOD) process used to build navigator.berlin:

- `planning-artifacts/`: briefs, PRD, architecture notes, epics, audits
- `implementation-artifacts/`: specs and stories with their review notes, `sprint-status.yaml`, `deferred-work.md`
- `specs/`: larger specs split into stories
- `spike-artifacts/`: schema snapshots from data spikes (read by `scripts/aggregate-wahl-data.ts`)

These files are not documentation. They record decisions as they were made and can be outdated. The code, the ADRs in `docs/adr/` and the other pages in `docs/` are authoritative.

Some files link to screenshots, raw translation data or brainstorming output. Those stayed local and are not in the repository.
