# Security Policy

## Reporting a vulnerability

Email **hey@navigator.berlin** with a description and steps to reproduce. Please do not open a public issue for security problems.

navigator.berlin is a solo-maintained open-source project. I read every report and answer as soon as I can. There are no fixed response times.

## Scope

- The code in this repository.
- The site at <https://navigator.berlin>.

The site sets no cookies and has no user accounts. Election results and layer data are public open data.

## Bug bounty

There is no bug bounty program. I credit reporters in the fix commit if they want it.
